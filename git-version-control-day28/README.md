# Backend Core Setup

This repository contains the foundational structure for the project, enforcing strict coding standards and automated formatting.

## Development Workflow
* **Black**: Uncompromising Python code formatter.
* **Flake8**: Tool for style guide enforcement.
* **Pre-commit Hooks**: Automated checks executed prior to every commit to ensure code quality.
