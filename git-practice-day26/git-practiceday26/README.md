# Git Version Control & Rebase Practice (Day 26)

This repository contains practical exercises for Day 26, focusing on advanced Git workflows, version control strategies, and conflict resolution.

## 📚 Core Topics Covered
- **Merge vs. Rebase:** Comparing branch merging (`git merge`) and linear history rebase (`git rebase`).
- **Merge Conflict Resolution:** Deliberately creating, analyzing, and manually resolving conflicts.
- **Interactive Rebase:** Cleaning up commit histories using `git rebase -i`.
- **Code Refactoring:** Structuring scripts into modular, clean Python functions.
